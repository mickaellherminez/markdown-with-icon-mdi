# Example markdown with icon

Add icons in markdown documentation.

> **Note:** this repository is the example of [this Stack Overflow answer](https://stackoverflow.com/a/59647194), written in 2020 and kept as it is. The import names below match the current `@mdi/js` (7.4): since 2020, `mdiGithubCircle` became `mdiGithub` and `mdiWindows` became `mdiMicrosoftWindows`. The PNG files keep their original names.

All icons come from [Material Design Icons](https://pictogrammers.com/library/mdi/) for png and [Ionicons](https://ionic.io/ionicons) for svg (but it works with any png or svg, example [Material Symbols](https://fonts.google.com/icons), [feathericons](https://feathericons.com/)... ).



**Example in html:**     `<img src="icons/png/github-circle.png">`

**Example in markdown:** `![image](icons/png/github-circle.png)`

> It is possible to use both syntax.
